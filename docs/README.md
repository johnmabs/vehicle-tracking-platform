# Documentation du projet

## Organisation

- `product/` : vision, utilisateurs, fonctionnalités et limites du produit.
- `architecture/` : architecture cible, contraintes techniques et décisions.
- `architecture/adr/` : décisions d'architecture (Architecture Decision Records).
- `learning/` : lots pédagogiques, objectifs, étapes, preuves et critères d'acceptation.
- `ROADMAP.md` : ordre prévu des lots et dépendances.

## Règle de documentation

Une modification importante du périmètre, de l'architecture ou des critères d'acceptation doit mettre à jour le document concerné dans le même changement que le code associé.
